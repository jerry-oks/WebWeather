# WebWeather
Приложение показывающее прогноз погоды.
Определяет местоположение пользователя, загружает погоду из сети на ближайшие несколько дней и позволяет менять параметры отображения информации.

## Стэк
+ Xcode
+ Swift
+ MVC
+ UIKit
+ Swift Package Manager (SPM)
+ Alamofire
+ REST API
+ JSON
+ MapKit
+ Storyboard
+ Auto Layout

## Цели и задачи
+ парсинг JSON вручную и автоматически (провайдер - Яндекс.Погода)
+ изучение MapKit, CoreLocation, UISegmentedControl, UICollectionView
+ работа с сетевыми запросами с помощью Alamofire
+ проработка передачи данных между экранами с помощью паттерна делегирования
